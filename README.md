# Recipkg 组织主页

本仓库维护 [Recipkg · 构方](https://github.com/recipkg) 的公开组织介绍。

- [`profile/README.md`](profile/README.md)：显示在组织主页上的中英介绍与项目入口。
- [`recipkg/recipkg`](https://github.com/recipkg/recipkg)：CLI、配方协议、迁移技能、示例和测试的主仓库。

修改组织介绍时编辑 `profile/README.md`。命令、格式和安装方式以主仓库为准；功能变更、问题反馈和配方贡献请前往主仓库。

This repository maintains the public profile for the Recipkg organization. The CLI, specification, skills, examples, and tests live in [recipkg/recipkg](https://github.com/recipkg/recipkg).
